# pokechan

スマホ対応のポケモンチャンピオンズ補助ツールです。

- M-C（Ver.1.2.0）の264種・新メガシンカ6種に対応
- 構築シート、スカウト判定、選出補助、MY BOXを1ページで利用可能
- 9/30時点のシーズンM-6シングル使用率トップ50を反映（[ポケナビの公開順位](https://pokenavi.jp/ranking/)。自動更新ではない）
- セグレイブ＋メガグソクムシャの二枚メガ構築を収録
- メガグソクムシャのであいがしら再装填サイクルを収録
- 10/14の手持ちから作成した「リザXラグラージ対策」「マンダガルド対策」を構築シート・パーティ登録のプリセットに追加。各6体の育成配分、基本選出、相手の型に応じた変更点を保存
- 手持ち向けのグソクムシャ・アシレーヌ・サザンドラ軸と整理候補を追加
- ヒートロトム所持時はグソクムシャ・アシレーヌ・ヒートロトムを基本選出として提案（9/12）
- 所持制限なしの最速スカーフイダイトウ構築を追加。メガミミロップで悪・ノーマルを処理し、ヒートロトムで草・鋼を削って終盤のおはかまいりを通す（9/12）。既存の手持ち優先構築は保持
- 選出表は開幕条件。対戦画面では両陣営のひんし数0〜2体を切替え、おはかまいりの威力50／100／150とダメージを比較可能（復活なしの3体戦。生存個体・HPの管理ではない）
- おはかまいりの非接触判定、乱数下限0.85、能力ポイント説明を修正。公式Ver.1.2.0で禁止された技を旧統計から除外
- M-6は10/7 10:59まで、M-Cは12/2 10:59まで（日本時間）。相手の型・採用率は旧収録データで、使用率順位の更新とは別
- 手持ちは固定キーでブラウザ保存。旧保存先からの移行、変更前の1世代バックアップ、保存失敗表示、別タブの変更反映に対応
- JSONファイルの保存・読み込みで端末を移行可能（ローカル版と公開版の保存領域は別）

検証: `node --test tests/*.test.cjs`

GitHub Pages: https://yuseis2005-crypto.github.io/pokechan/

9/30確認元: [公式M-Cルール](https://champions-news.pokemon-home.com/ja/page/816.html)、[公式Ver.1.2.0変更点](https://champions-news.pokemon-home.com/ja/page/817.html)、[おはかまいりの仕様](https://www.serebii.net/attackdex-champions/lastrespects.shtml)。計算は概算で、状態異常・残りHP・技固定等の全状況には対応していません。
